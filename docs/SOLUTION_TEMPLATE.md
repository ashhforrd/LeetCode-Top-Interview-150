# Solution note template

Use this outline when documenting a new solution. The implementation itself
stays in the problem's `.py` file.

## Approach

Explain the main observation and the data structure or algorithm used. Focus
on why it works rather than restating the code line by line.

## Complexity

- Time: `O(...)`
- Space: `O(...)`

## Edge cases

- Empty or minimum-size input
- Duplicate values
- Already sorted or reverse-sorted input
- Constraints specific to the problem

## Verification

List a normal case, a boundary case, and a case that would break a common
incorrect approach.
